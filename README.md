# Gemstone-Gallery
A full-stack web application for browsing and purchasing gemstones — built with Node.js, Express.js, EJS, and SQLite. Features a complete e-commerce flow including user authentication, a shopping cart, checkout, and a dedicated admin panel for product management.

# Features
User Authentication: Secure register/login system with session management
Product Browsing:Browse gemstone listings with images, descriptions, and pricing
Shopping Cart: Add, update, and remove items with real-time quantity tracking
Checkout Flow:  Complete order placement with order summary
Admin Panel: Protected dashboard to add, edit, and delete gemstone listings
Persistent Storage: All data stored using better-sqlite3 for fast, reliable local queries

# Tech Stack
Layer            Technology
Runtime          Node.js
Framework        Express.js
Templating       EJS(Embedded JavaScript)
Database         SQLite via better-sqlite3
Auth             Express Session
Styling          CSS / Bootstrap

# Getting Started
**Prerequisites**
Node.js v16+
npm

**Installation**
# Clone the repository
git clone https://github.com/gemini-create/gemstone-gallery.git
cd gemstone-gallery

# Install dependencies
npm install

# Start the app
node server.js
Visit http://localhost:3000 in your browser.
